# yameen.app (يمين)

Arabic text tools for designers, video editors and game developers:
type Arabic, preview it in free Arabic fonts, copy a version that works in
software without Arabic support, or export it as PNG/SVG.

All text and font processing runs in the browser. The Laravel server renders
pages and manages accounts, credits and payments.

## Stack

- Laravel 13, PHP 8.3, MySQL (SQLite in-memory for tests)
- Blade + Alpine.js, Vite, Tailwind CSS v4 (custom tokens only, default palette removed)
- Self-hosted fonts (`@fontsource/*`, bundled by Vite with hashed filenames)
- Pest (PHP tests), Vitest (JS tests)

## Local setup

```bash
composer install
npm install
cp .env.example .env && php artisan key:generate
php artisan migrate
npm run build   # or: npm run dev
php artisan serve
```

## Tests

```bash
./vendor/bin/pest
npm test
```

## Structure

- `routes/web.php` registers `routes/localized.php` once per locale:
  Arabic at `/`, English under `/en`. Route names are `{locale}.{name}`;
  use `lroute('fix')` in views.
- `config/yameen.php`: locales, software pages, font styles.
- `lang/{ar,en}/ui.php`: interface strings.
- `resources/css/app.css`: design tokens (`--paper`, `--lav-*`, `--ink`, ...).
  Colours are only defined as CSS variables so a dark theme can be added later.
- `resources/svg/wordmark.svg`: wordmark outlines generated from Reem Kufi 600.

## Fonts

Font files are built from [google/fonts](https://github.com/google/fonts) and are
not committed. On a fresh server:

```bash
pip install -r scripts/fonts/requirements.txt
php artisan migrate
php artisan fonts:sync
```

`fonts:sync` runs `scripts/fonts/build.py`, which:

1. Clones google/fonts sparsely (only `ofl/*/METADATA.pb`, then the Arabic families).
2. Keeps families whose subsets include `arabic`, plus the Latin families named in
   `resources/fonts/pairings.json`.
3. Instances variable fonts to static weights and writes, per weight, a full TTF
   (export), a full WOFF2 and an Arabic-only preview WOFF2, with hashed filenames.
4. Checks each family for the presentation forms the fixer outputs and for GPOS mark
   positioning of diacritics.
5. Writes `storage/app/fonts/fonts.json`; the command imports it into the `fonts` table
   and links `public/font-files` to the files.

Re-running only rebuilds families whose folder changed. To re-import after editing
`resources/fonts/overrides.json` (styles such as kufi/naskh, popularity order,
sample text, hidden families):

```bash
php artisan fonts:sync --skip-build
```

Files are served from `/font-files/...` (not `/fonts/...`, which are page routes).
Configure Cloudflare/your web server to cache that path with a long `Cache-Control`.

## Preview on GitHub Pages

`.github/workflows/pages.yml` runs the tests, builds the fonts, exports every page with
`php artisan site:export` and pushes the result to the `gh-pages` branch on each push.
Preview: https://safaa98-iraq.github.io/yameen.app/

Only browser-side tools work there; accounts, credits and payments need the PHP server.

## Content and SEO

- Page text lives in `resources/content/{ar,en}/*.md` (front matter: `title`,
  `description`, `h1`, `intro`, `faq`, plus `paste_steps`/`paste_note` on app pages).
  Blog guides are in `resources/content/{ar,en}/blog/`. Search for `TODO(verify)` before launch.
- `resources/js/data/ar-words.txt` (PDF word repair) is derived from FrequencyWords (Hermit Dave, CC BY-SA 4.0) and wikipedia-word-frequency (Ilya Semenov, MIT; Wikipedia counts); see `resources/js/data/README.md`.
- `scripts/content/software_pages.py` generated the first drafts of the `/fix/{app}` pages;
  edit the Markdown directly (re-running the script overwrites it).
- Every page has a canonical URL, hreflang, Open Graph tags and JSON-LD
  (BreadcrumbList; WebApplication on tools; Article on guides).
- `/sitemap.xml` and `/robots.txt` are generated. Set `SEO_NOINDEX=true` on preview
  deployments: it adds `noindex` and makes robots.txt block everything.
- Font share images (`og.*.png`) are generated by `fonts:sync`; `public/og-default.png` is the fallback.
