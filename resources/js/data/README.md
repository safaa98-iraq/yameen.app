# ar-words.txt

Arabic words ranked by frequency (one per line, most frequent first), used by the
PDF fix to repair letter pairs swapped by some PDF exporters.

Derived from **FrequencyWords** by Hermit Dave (OpenSubtitles 2018, Arabic),
https://github.com/hermitdave/FrequencyWords, licensed
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This file is a
derivative work (filtered, deduplicated, prefixed forms removed) and is
distributed under the same licence.

Rebuild with `python3 scripts/content/build_dictionary.py path/to/ar_full.txt`.
